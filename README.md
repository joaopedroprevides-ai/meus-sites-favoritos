
# Meus Sites Favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade de Desenvolvimento Web.

O objetivo é apresentar meus cinco sites favoritos utilizando HTML e CSS.

## Tecnologias utilizadas

- HTML5
- CSS3

## Sites apresentados

1. YouTube
2. Google
3. GitHub
4. Canva
5. ChatGPT

## Estrutura do projeto

- index.html: estrutura da página.
- style.css: estilização da página.
- imagens/: imagens dos logotipos.
- capturas/: capturas do código e da página executada.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
